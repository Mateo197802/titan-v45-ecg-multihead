This summary documents the revision decisions using the archived evidence, results and verification records. Its scope is editorial integration and aggregate verification; no new model training or ECG inference was performed during this revision.

\section*{Decisions and supporting evidence}
\begin{enumerate}
\item \textbf{Preserve the original results and their denominators.}
P6 retains 95.19\% top-1 accuracy and 80.09\% mean binary F1 on 1,643 ECGs. P4 retains 80.23\% mean binary accuracy and 79.35\% macro-F1 on 962 ECG--label observations from 733 distinct ECGs. These are selected retrospective estimates; the new experiment does not replace them.

\item \textbf{Authenticate the supplied package before integration.}
The ZIP is byte-identical to the public package. The verifier checked 57 files and 46 provenance records against the original Git objects. The primary evidence is pinned to commit \texttt{63c74b3fde2c51f7f8cd}\allowbreak\texttt{e4ad396d77a1bd16cb29}. Hashes establish file identity; they do not certify the complete training history.

\item \textbf{Define the scope of CODE precisely.}
The candidate received supervised training on CODE patients and was evaluated on 4,921 ECGs from 3,891 other, reserved patients. The audit reports zero patient-key overlap across the four CODE partitions. This supports a patient-disjoint evaluation within CODE following adaptation. Independent institutional confirmation and external P4 evaluation remain pending. The five endpoints are AFIB, SB, STACH, RBBB and 1AVB.

\item \textbf{Compare the same ECGs and retain adverse findings.}
P6, P8 and the candidate use the same ECGs and references in this five-endpoint comparison. Their processing paths and operating points differ, so the gain cannot be attributed to one isolated component. AFIB/SB sensitivity losses and lower 1AVB positive predictive value relative to P8 remain explicit. The candidate did not meet the macro-F1 target of 0.70 or all promotion safeguards.
\end{enumerate}
