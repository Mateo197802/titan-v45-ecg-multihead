# Provenance

`source_inventory.json` is an archival inventory captured on 2026-06-29 for an isolated V3C-V3AG source root. Its paths are relative to that external root and contain no workstation or cluster identifiers. The listed source files are not bundled here, so their hashes cannot be recomputed from this repository copy. This inventory records historical provenance; it is not a complete training archive, a current line-by-line source map, or proof that the reported training run can be reproduced.
