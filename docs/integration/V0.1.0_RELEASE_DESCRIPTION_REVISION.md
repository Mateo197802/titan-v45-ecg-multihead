## Replacement description

**TITAN V4.5 ECG Multihead v0.1.0**

TITAN V4.5 is a research-oriented, multihead deep learning framework for 12-lead electrocardiogram analysis. It combines convolutional and Transformer-based representations with specialized configurations for cardiac rhythm and ECG pathology classification.

This release provides the initial public research artifacts, including model architecture information, rhythm and pathology configurations, evaluation summaries, reproducibility manifests, model assets, and integrity checks.

The repository documents three evaluated configurations:

- **Primary6:** Six-class cardiac rhythm classification.
- **Primary8:** Eight-class cardiac rhythm classification.
- **Primary4:** Four-class ECG pathology classification.

Reported performance metrics correspond to their respective evaluation datasets, class definitions, and protocols. Results from different configurations should not be interpreted as directly comparable unless their evaluation conditions are aligned.

The repository includes detailed documentation of experimental methods, data sources, performance metrics, reproducibility procedures, and identified limitations.

These results represent the documented research evaluations and do not establish independent institutional or prospective clinical validation.

For further information, consult the repository README, evaluation evidence, model documentation, and release manifests.
