# Calibration and sensitivity gate

No external calibration, threshold fit, or sensitivity comparison is reported. The label-blind probe loads the released profiles and thresholds without adapting them; it does not read reference statements. It is not a performance result. Stage A comparisons are historical context for this new branch, not reused external observations.

An adapted study must select heads on MIMIC training/validation, calibrate once on disjoint calibration patients, and lock the candidate and evaluation rules before test access. The promotion minimum is +0.03 macro-F1, paired patient-bootstrap lower bound > 0 and no sensitivity decrease > 0.05 on an adequately supported class. Calibration deterioration and abstention margins, minimum supports, and any missing-estimate policy must be frozen before performance. CODE-15% is not a tuning set. No promotion is possible from this preflight.
