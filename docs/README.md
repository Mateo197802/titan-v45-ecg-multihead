# Documentation

This directory records architecture, evaluation protocols, CEDIA execution, provenance, release procedures, and scientific claim boundaries. Machine-readable profile contracts remain authoritative for loading artifacts; canonical result JSON remains authoritative for reported metrics.

See [Evidence and Claim Boundaries](evidence-status.md) for the current Primary6, Primary4, and Primary8 status, metric definitions, source links, and the command that recomputes the published metrics from tracked predictions.

The [frozen waveform audit](frozen-waveform-audit.md) reports the newer CEDIA inference and matched-reference comparison. The [disposition index](revision-data-dispositions.md) distinguishes new results, absent historical evidence and deferred external evaluation.

The [`exploratory SPH PAC probe`](external_validation/sph_pac_probe_results.md) records its frozen inputs, CEDIA execution receipts, aggregate metrics, duplicate sensitivity and privacy-safe figure. It is not independent external or clinical validation.

The [29 October historical recovery update](recovery-status-20261029.md) documents recovered source identity, header modifications, search coverage and remaining reproducibility gaps without regenerating the manuscript or asserting that reviewer requests are all closed.

The [36-comment reviewer closure action plan](reviewer_closure/REVIEWER_36_CLOSURE_ACTION_PLAN.md) is a reviewer-only view derived from the authoritative [48-item matrix](reviewer_closure/REVIEWER_48_DETAILED.md). It preserves the 12 internal audits separately and records technical status, reviewer satisfaction, evidence and remaining actions. Related author-review materials include the [reproducibility gaps](reviewer_closure/REVIEWER_REPRODUCIBILITY_GAPS.md), [code/formula audit](reviewer_closure/REVIEWER_CODE_AND_FORMULA_AUDIT.md), [figure/table proposals](reviewer_closure/REVIEWER_FIGURE_TABLE_CORRECTIONS.md), [populated aggregate tables](reviewer_closure/REVIEWER_PROPOSED_TABLES.md), [claim dispositions](reviewer_closure/REVIEWER_CLAIM_WITHDRAWAL_DECISIONS.md) and [response evidence draft](reviewer_closure/REVIEWER_RESPONSE_EVIDENCE_DRAFT.md). These are proposals, not edits to the submitted manuscript or responses, and require author review.
