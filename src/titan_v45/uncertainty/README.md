# Uncertainty

Implements MC-Dropout sampling, predictive entropy, mutual information, and explicit quarantine rules for uncertainty analysis.

The categorical MC-Dropout utility is not a replacement for multilabel specialist scoring. The selected-waveform audit does not apply its output as a quarantine policy: no frozen linked threshold/uncertainty contract was established. `quarantine_not_assessed` is distinct from retained, quarantined and no score; the aggregate rate is undefined when no inputs are assessed.
