# Data Module

Implements signal preprocessing and manifest validation. Public manifests use release-relative record paths or stable record identifiers and must never embed workstation or CEDIA paths.

`reconstructed` provides a source-backed WFDB preparation path: P4 single-window and rhythm sliding-window modes. These are distinct contracts; neither is labeled the exact missing historical loader. The preparer preserves lead masks and rejects an unusable input rather than converting it to a negative.
