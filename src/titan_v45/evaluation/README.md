# Evaluation

Defines top-1 and classwise metrics, canonical result registry, primary reports, and head-level evaluation. Primary metrics require declared classes and full eligible coverage; cascade and quarantine results remain secondary.

`waveform_reference` joins sealed waveform decisions to the retained references only after routing. It validates inventory and duplicate keys, compares new and archived scores on identical rows, and reuses the existing metrics and ECG-cluster bootstrap. Missing scores remain outside the scored denominator, and exact-key overlap does not establish patient identity.
