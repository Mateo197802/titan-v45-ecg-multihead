# Cascade

The `policy` module declares the secondary class order. `waveform` builds a label-free inventory and accounts for scored, unscored and unassessed paths. `run_pathology` and `run_rhythm` connect the verified release assets to waveform preparation and frozen model scoring. The latter resolves one documented CODE-test archive alias and rejects path collisions.

The runners do not promote auxiliary scores into diagnoses, create an Other class, or apply an unlinked quarantine policy. The private ledgers account for each selected key; export aggregate data only. See the [runbook](../../../docs/frozen-waveform-audit.md).
