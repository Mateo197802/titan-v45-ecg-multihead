# Manuscript Figures

This directory contains only the 14 PNGs referenced by the submitted manuscript. Their SHA-256 hashes are recorded in `figure_manifest.json`; the PDF, TeX source, and ZIP are not included.

Verify the files from the repository root with `python tests/figure_evaluation/scripts/verify_figure_assets.py --manifest outputs/figures/figure_manifest.json --figures outputs/figures --root .`.
