# SPH ECG Data License And Attribution

The source is the Shandong Provincial Hospital (SPH) 12-lead ECG dataset,
version 1, collection DOI `10.6084/m9.figshare.c.5779802.v1`. The separate
Figshare items for waveforms, metadata, and the diagnostic-statement dictionary
reported `CC0` in the Figshare API on 2026-11-09:

- [ECG records](https://springernature.figshare.com/articles/dataset/ECG_records/17912444), DOI `10.6084/m9.figshare.17912444.v1`.
- [Attributes of ECG records](https://springernature.figshare.com/articles/dataset/The_attributes_of_ECG_records/17912441), DOI `10.6084/m9.figshare.17912441.v1`.
- [Diagnostic statement dictionary](https://springernature.figshare.com/articles/dataset/diagnostic_statement_dictionary/17912507), DOI `10.6084/m9.figshare.17912507.v1`.

The item-level license metadata is distinct from the license on the dataset
descriptor article. Recheck the version-specific item terms before distributing
any source files. TITAN's repository contains no SPH waveforms, patient IDs, or
row-level predictions; only aggregate evidence may be published here.

Dataset descriptor: Liu et al., “A large-scale multi-label 12-lead
electrocardiogram database with standardized diagnostic statements,”
*Scientific Data* 9, 272 (2022),
[doi:10.1038/s41597-022-01403-5](https://doi.org/10.1038/s41597-022-01403-5).
